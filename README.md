# Data and Code for Paper

## Overview

This repository contains the replication code for the main descriptive statistics, figures, and regression tables reported in the paper. The Python notebook reproduces Table 1, Figure 2, and Figure 3. The Stata do-file reproduces Table 2 and Table 3 and also generates the CSV files used by the Python notebook to draw Figure 2 and Figure 3.

## Data Availability

Because GitHub imposes file size limits, the dataset is not stored directly in this repository. The full replication dataset is available through Harvard Dataverse:

[https://doi.org/10.7910/DVN/RVB41B](https://doi.org/10.7910/DVN/RVB41B)

## Dataset Descriptions

The following files are used in the replication workflow.

### PNAS_revision_regression_upload_data.csv

The anonymized core dataset used for the main regression analyses, descriptive statistics, and figure construction. This file includes scientist-year observations, anonymized scientist identifiers, treatment status, funding outcomes, pivot-size measures, control variables, and subgroup indicators.

### Fig3_event_study_data.csv

Dataset used to produce Figure 2. It contains event-study coefficient estimates and corresponding 95% confidence intervals for U.S. federal funding, U.S. funding, total funding, and pivot size. This file is generated by the Stata script `replicate_tables_2_and_3.do`.

### Fig4_did_topic_data.csv

Dataset used to produce Figure 3. It contains the estimated moderation effects of `DID × Pivot Size` across subgroup analyses, including name-inferred ethnicity, list-related fields, and career stage. This file is generated by the Stata script `replicate_tables_2_and_3.do`.

## Code Structure

### replicate_table1_figure2_figure3.ipynb

Python notebook used to reproduce:

- Table 1: descriptive statistics and treatment-control comparisons
- Figure 2: event-study estimates
- Figure 3: heterogeneity analyses

The notebook reads `PNAS_revision_regression_upload_data.csv`, `Fig3_event_study_data.csv`, and `Fig4_did_topic_data.csv`, and writes outputs to the `results/` folder.

### replicate_tables_2_and_3.do

Stata script used to reproduce:

- Table 2: baseline DID estimates
- Table 3: associations between pivot size and differential changes in funding
- `Fig3_event_study_data.csv`
- `Fig4_did_topic_data.csv`

Run this Stata script before running the Python notebook if you want to regenerate the figure input files from the core dataset.

## Recommended Workflow

1. Download `PNAS_revision_regression_upload_data.csv` from Harvard Dataverse.
2. Place it in the same folder as the code files.
3. Run `replicate_tables_2_and_3.do` in Stata.
4. Run `replicate_table1_figure2_figure3.ipynb` in Jupyter.
5. Check the `results/` folder for reproduced tables and figures.
